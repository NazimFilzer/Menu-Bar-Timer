📐 UI Space & Structural Tradeoff Comparison Fixed Popover Width: 330px
Design Dimension Variant A (History Drawer) Variant B (Action Tab Morph) Variant C (Native Sheet Modal)
Idle Height Added 0 px (Header button) 0 px (Reuses action row) 0 px (Trigger in header)
Active Entry Height Takes ~84px above sprints 0 px net (in-place swap) Overlays ~220px sheet

Ergonomics & Density Tight, high information density Zero height penalty, ultra-clean Most relaxed, touch-friendly
Engineering Recommendation:
• Variant A (History Drawer) is the most intuitive for day-to-day workflow because the user is thinking "I want to add an entry to my history list." It consumes 0px of vertical space until opened, then slides away on save.
• Variant B (Action Tab Morph) is the most space-efficient for the 330px popover because it reuses the exact action footprint. Perfect if you prefer keeping the popover height 100% constant.
• Variant C (Native Sheet) is the most robust if you want advanced features like break deduction, ±15m steppers, and goal impact previews without cramping the main window.
