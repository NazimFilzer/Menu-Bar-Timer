# Insights prototype

Open `insights-prototype.html` in a browser. It opens the selected mix, D.
Use Week and Analytics to switch pages. Use the bottom arrows to compare A, B, C, and D.

Selected designs:
- Week comparison: B, with a short explanation, bars by day, and an expandable table.
- Sprint patterns: A, with net duration statistics, duration groups, and pause statistics.
- Daily goal consistency: C, with a grid of days across 13 weeks.

The combined D layout is ready for review. This is sample data with no persistence.
Today does not count in the daily goal rate. Days off and future days do not count.
The sample uses the same 8-hour goal for all past days.
The comparison at the same clock time estimates paused work within a sprint.
Exact pause timestamps are not available in the current app model.

Archive branch: `prototype/insights-selected`.
Production integration is a separate step after review of the combined design.
